## 📊 五大核心业务管控模块说明

### 1. 📢 全盘经营监控与 DuPont 因素贡献度归因
* **业务卡点**：解决 GMV 波动时定性扯皮问题。
* **内置算力**：采用 DuPont 因素分解公式：
  $$\Delta GMV = \Delta Traffic \times CVR_{prev} \times AOV_{prev} + Traffic_{prev} \times \Delta CVR \times AOV_{prev} + Traffic_{prev} \times CVR_{prev} \times \Delta AOV$$
* **输出物**：实时绘制 Waterfall 瀑布图，一键输出符合歪马规范的《歪马经营日报》Markdown 诊断报告与 Top 10 断货损失表格。

### 2. 🍷 商品四象限策略与自动汰换算力引擎
* **业务卡点**：解答 Leader 关注的*“560 还是 580 个 SKU 合适？如何兼顾丰富度与经营效益？”*问题。
* **内置算力**：基于近 30 天 GMV 与毛利率的动态 **P50 分位数**切分四象限（规模品/流量品/利润品/培育品），结合 `动销率 < 5% 且 毛利 < 10% 且 上架 > 90天` 自动筛选淘汰 SKU。
* **输出物**：一键计算淘汰 SKU 数量、释放资金（如 ¥18.6万元）与全盘品效提升预估，导出《采销确认表》。

### 3. 💰 价格弹性 $Ed$ 定价模型与补贴 ROI 优化器
* **业务卡点**：解答 *“1元/2元降价给哪个品收益最大？如何避免补贴误伤？”* 问题。
* **内置算力**：根据利润最大化价格 $P^* = MC \times \frac{Ed}{Ed-1}$ 计算理论最优定价，展示 1元/2元/5元 降价敏感性矩阵；利用 PSM 剔除自然 GMV，算真实增量 ROI，误伤率 $>40\%$ 自动预警。

### 4. 🚚 供应商 100 分制评分卡与 ROP 供应链协同
* **业务卡点**：量化管控上千家供应商与采销团队谈判。
* **内置算力**：按 价格(25%)+缺货(20%)+及时(20%)+次品(20%)+售后(15%) 自动计算 100 分制得分与 A/B/C/D 分级；同时计算安全库存 $ROP = \text{日均销量} \times L + SS$。
* **输出物**：一键生成向 C/D 级供应商下发的数据凭证与采销降价谈判话术。

### 5. 🤖 采销中台 AI 智能分析与代码生成 Copilot
* **业务卡点**：展示采销中台如何借助 AI 将取数与归因效率提升 50% 以上。
* **内置算力**：模拟 Airflow + Hive + Python + LLM 自动化链路，输入自然语言指令（或点击预设气泡），秒级生成对应的 Hive SQL 取数脚本、Python 分析代码及采销执行指令。
